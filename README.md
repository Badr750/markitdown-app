# MarkItDown Web App

A clean, user-friendly web app that converts files to Markdown instantly.
Built on top of Microsoft's open-source MarkItDown library.

## Supported Formats
PDF, Word (.docx), Excel (.xlsx), PowerPoint (.pptx), CSV, HTML, TXT, JSON, XML, Images, ZIP

## Features
- Drag & drop interface
- Instant Markdown preview
- Copy to clipboard
- Download as .md file
- Token count estimate for AI usage

## Run Locally
pip install -r requirements.txt
python app.py

Then open http://localhost:5000
